# 🏪 Superstore Sales Analysis - Excel Dashboard

## 📌 Project Overview
An interactive Excel dashboard built using real Superstore dataset 
with comprehensive sales analysis across categories, regions, and segments.

## 🛠️ Skills Used
- VLOOKUP & INDEX-MATCH
- Pivot Tables & Pivot Charts
- IF, COUNTIF, SUMIF, AVERAGEIF
- Conditional Formatting
- Data Cleaning (TRIM, UPPER, LOWER, LEN, LEFT, RIGHT, MID)
- Dashboard Design

## 📊 Key Insights
- **Technology** has highest sales: $836,154
- **West** region leads with 3,203 orders
- **Standard Class** is most used ship mode (61%)
- **Consumer** segment generates highest profit: $134,119
- **Phones** are top sub-category: $330,007
